# SEO Optimization for Seller Products

Improving product visibility in buyer search results.

## Key Factors

| Factor | Impact | How to Optimize |
|--------|--------|-----------------|
| **Keywords in description** | High | Include category, variety, origin, attributes |
| **Price competitiveness** | High | Match or beat competitors |
| **Image quality** | Medium | High-res, white background, multiple angles |
| **Product ID format** | Low | Use descriptive, readable IDs |
| **Tags** | High | Origin, dietary, certifications |

## Description Optimization

### Good Example

```
Premium organic Alphonso mangoes from Ratnagiri, Maharashtra.
Grade A, hand-picked, naturally ripened. Rich, sweet flavor.
Perfect for desserts and smoothies.
```

### Poor Example

```
Mango
Good quality
```

## Keyword Strategy

**Include:**

- Category name (mango, groceries, fruits)
- Variety (alphonso, kesar, dasheri)
- Origin (Ratnagiri, Konkan, Gujarat)
- Attributes (organic, premium, fresh, grade A)
- Use cases (desserts, smoothies, salads)

**Avoid:**

- Keyword stuffing
- Irrelevant terms
- Duplicate words

## Price Positioning

### Strategy

| Current Position | Action | Expected Lift |
|------------------|--------|--------------|
| Top 3 | Maintain | Baseline |
| 4-10 | Reduce 5-10% | +2-3 positions |
| 11-20 | Reduce 15-20% | +5-8 positions |
| 20+ | Reduce 25%+ | +10+ positions |

### Calculation

```
competitor_avg = avg(top_5_prices)
optimal_price = competitor_avg * 0.95
```

## Image Best Practices

1. **Resolution**: 1000x1000px minimum
2. **Background**: White or plain
3. **Lighting**: Bright, even
4. **Angles**: Front, side, close-up
5. **Format**: JPG or WebP
6. **Size**: < 200KB compressed

## Tag Recommendations

| Category | Recommended Tags |
|----------|------------------|
| Grocery | origin, dietary (veg/organic), state |
| Fashion | material, size, color, pattern |
| Electronics | specs, warranty, compatibility |
